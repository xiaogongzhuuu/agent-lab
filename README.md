# Agent Trace Lab

一个最小化的工具调用实验台。输入任务并配置模拟工具，切换架构观察同一任务的 trace。页面先显示每步的输入、决定和结果；完整请求与响应 JSON 可按需展开。

## 本地运行

需要 Node.js 22.13+ 和 DeepSeek API Key：

```bash
npm ci
```

在项目根目录创建 `.env.local`：

```text
DEEPSEEK_API_KEY=你的密钥
```

运行 `npm run dev`，打开 [http://localhost:5173/](http://localhost:5173/)。

## 三种架构

- **ReAct 循环**：每次模型调用后执行工具，把结果加入上下文，再让模型决定下一步。
- **固定流程**：从任务中找出点名的工具，按工具列表顺序执行，最后让模型总结；没有点名工具时执行全部工具。
- **先计划后执行**：模型先输出工具清单和参数，执行器依次执行，最后让模型总结；执行过程中不重新规划。

工具的 `result` 是用户配置的模拟 JSON。每个工具最多调用一次，最多配置 8 个工具。页面可展开完整模型请求和响应，但不会展示 API 密钥或模型内部思维过程。

## 对照实验

点击“对照三种架构”，页面会用相同任务和工具依次运行三种架构，保留各自的 trace，并显示模型请求次数、工具顺序和总耗时。切换卡片可查看每条详细轨迹。

“条件任务”示例让工具 a 返回 `need_b`。把它设为 `false` 时，可观察 ReAct 是否根据结果跳过 b；固定流程和先计划后执行的步骤在执行前确定，不会在中途重新规划。

npm test
npm run build
