# Agent Trace Lab

一个最小化的 Agent 工具调用实验台。输入任务、配置模拟工具，对照不同架构如何选择工具、传递结果并生成结论。运行轨迹按步骤展示，完整请求与响应 JSON 可按需展开。

## 本地运行

需要 Node.js 22.13+ 和 DeepSeek API Key：

```bash
npm ci
```

在项目根目录创建 `.env.local`：

```text
DEEPSEEK_API_KEY=你的密钥
```

运行 `npm run dev`，打开 [http://localhost:5173/](http://localhost:5173/)。

## 三种架构

- **ReAct 循环**：每轮最多执行一个工具，把结果加入上下文，再让模型决定下一步。同一任务中每个工具最多调用一次；多调用或重复调用会被后端拦截，原始响应仍保留在 trace 中。
- **固定流程**：从任务中找出点名的工具，按工具列表顺序执行，最后让模型总结；没有点名工具时执行全部工具。
- **先计划后执行**：模型先输出工具清单和参数，执行器依次执行，最后让模型总结；执行过程中不重新规划。

工具的 `result` 是用户配置的模拟 JSON。每个工具最多调用一次，最多配置 8 个工具。页面可展开完整模型请求和响应，但不会展示 API 密钥或模型内部思维过程。

## 对照实验

点击“对照三种架构”，页面会用相同任务和工具依次运行三种架构，保留各自的 trace，并显示模型请求次数、工具顺序和总耗时。切换卡片可查看每条详细轨迹。

“条件任务”示例让工具 a 返回 `need_b`。把它设为 `false` 时，可观察 ReAct 是否根据结果跳过 b；固定流程和先计划后执行的步骤在执行前确定，不会在中途重新规划。

ReAct 调用 a、b 的正常过程为：模型选择 a → 执行 a → 模型读取 a 的结果并选择 b → 执行 b → 模型总结，共 3 次模型请求、2 次工具调用。如果观察 a 后无需 b，则可在第 2 次模型请求时结束。

## 查看 trace

选择架构后，右侧显示对应流程图。运行轨迹会标出模型请求、工具参数、工具返回值和最终回答；点击关键字段可追踪它在模型响应、工具调用、Observation 和下一轮请求中的位置。需要排查细节时再展开完整 JSON。左侧栏可收起。

模型请求次数按实际发给 DeepSeek 的请求计数，工具调用次数按实际执行的工具计数。固定流程通常只在执行完工具后请求模型总结；先计划后执行通常有计划和总结两次模型请求。实际次数以 trace 为准。
